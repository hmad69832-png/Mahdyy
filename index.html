📚 عربي - اسم الفاعل (مذكرة مهدي كاملة)
يعني ايه؟ اسم بيدل على اللي عمل الفعل الصياغة: 1- ثلاثي = وزن فاعل كتب=كاتب، لعب=لاعب، فهم=فاهم قال=قائل (أجوف نقلب ألف همزة) قضى=قاضٍ (ناقص نحذف الياء في الرفع والجر) 2- غير ثلاثي = ميم مضمومة + كسر قبل الآخر أكرم=مُكرِم، علّم=مُعلِّم، انطلق=مُنطلِق، استخرج=مُستخرِج عمله: بيرفع فاعل وينصب مفعول مثال: الكاتب درسُه واضح = درسه مفعول به لاسم الفاعل
تدريب 1: هات اسم الفاعل من (صام - دعا - استفهم)
ج: صائم - داعٍ - مُستفهِم
تدريب 2: استخرج اسم الفاعل: "المؤمن صادق في قوله"
ج: المؤمن (من آمن) - صادق (من صدق)
💻 حاسب آلي - ذكاء اصطناعي وبايثون
قانون y = w*x + b y = التوقع، x = المدخل، w = وزن بيتعلم، b = تحيز مثال: عايز تتوقع سعر شقة مساحتها x=100 لو w=0.5 و b=10 => y=60 ألف بايثون: - list = [1,2,3] بتحفظ بيانات كتير - for x in list: بتلف على كل قيمة - def predict(x): return 2*x+1 بتعمل دالة - AI بيجرب w و b كتير لحد ما الخطأ يصغر مثال كود: data = [1,2,3] for x in data: print(2*x+1) # 3,5,7
